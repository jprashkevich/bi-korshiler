# Тихие рилсы — агент для Claude Code

Агент собирает партии текстовых рилсов (хук поверх видео из вашей галереи),
пишет описания с кодовым словом и тексты для бота, помогает публиковать их как
**Trial Reels** и анализировать статистику. Снимать и говорить на камеру не нужно.

## Что нужно
- Claude Code (терминал или приложение) — агент работает с файлами на вашем компьютере
- Node.js 18+ и ffmpeg (агент подскажет команду установки, если их нет)
- 5–10 коротких вертикальных видео из галереи (кофе, дорога, рабочее место, город)

## Быстрый старт
Откройте папку `reels-agent` в Claude Code и напишите:

```
/reels-setup
```
Агент задаст вопросы о вашей аудитории и продукте, покажет варианты оформления,
подготовит ваши видео и установит всё необходимое.

```
/reels-batch
```
Соберёт первую партию: 10 рилсов с разными хуками, описания и кодовые слова.
Готовые файлы — в `batches/<дата>-batch-01/out/`.

```
/reels-hooks
```
Если скинете в `hooks/inbox/` скриншоты вирусных роликов вашей ниши — агент
разберёт их заголовки и будет опираться на них, а не только на общий банк.

```
/reels-review
```
Через 1–3 дня после публикации: пришлите скриншоты статистики или заполните
`tracking/stats.csv` — агент найдёт победителей и соберёт следующую партию.

## Публикация
Каждый ролик выкладывайте с включённым тумблером **Trial**, не меньше 5 в день,
3–5 дней без выводов. Подробности — `docs/publishing.md`.

## Структура
```
config/      профиль и стиль          hooks/      банк хуков и ваши хуки
templates/   описания и бот           docs/       публикация, футажи
batches/     партии (batch.json, out) tracking/   статистика
footage/raw  ваши исходные видео      remotion/   рендер (не трогать руками)
scripts/     подготовка видео, рендер, валидация
```

## Ручные команды (если нужно без агента)
```
bash scripts/prepare-footage.sh                 # видео из footage/raw → 1080x1920
node scripts/new-batch.mjs                      # заготовка партии
node scripts/validate-batch.mjs batches/<имя>   # проверить batch.json
node scripts/render-batch.mjs batches/<имя> --stills   # png-превью
node scripts/render-batch.mjs batches/<имя>     # mp4
cd remotion && npm run studio                   # живой предпросмотр в браузере
```

Шрифты (Montserrat, Inter, Playfair Display, Oswald, PT Mono) — лицензия SIL OFL,
лежат в `remotion/public/fonts/`.

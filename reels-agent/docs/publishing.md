# Публикация: пробные рилсы (Trial Reels)

## Что такое Trial
Trial Reels показываются **только тем, кто на вас не подписан**. Подписчики их не
видят, лента аккаунта остаётся чистой. Через ~24 часа видна статистика, и ролик
можно оставить пробным, перевести в обычный (кнопка «Share to everyone») или удалить.
Instagram может сам предложить перевести ролик всем, если он набирает.

Доступность: функция включается у аккаунтов постепенно; если тумблера нет —
проверьте, что аккаунт профессиональный (Creator/Business) и приложение обновлено.

## Как публиковать
1. Создать Reel → загрузить mp4 из `batches/<партия>/out/`.
2. Описание — из `batches/<партия>/out/captions/<id>.txt` (скопировать целиком).
3. Перед кнопкой «Поделиться» включить тумблер **Trial**.
4. Звук: ролики «тихие», но можно добавить трендовый звук из библиотеки на 10–30% громкости — это не ломает механику.
5. Обложка: кадр с хуком (первый кадр уже содержит текст).

## Режим и ожидания
- **Не менее 5 роликов в день**, разные хуки, можно одинаковые футажи.
- Первые реакции — через сутки. Алгоритму нужно **3–5 дней**, чтобы раскачаться.
- Не делать выводов по 4 роликам. Минимальная выборка — 20–25 роликов.
- Выкладывать в одно время суток, интервалы 1–3 часа между роликами.

## Что фиксировать (tracking/stats.csv)
Через 24 ч и через 72 ч после публикации: просмотры, досматривания (если видно),
лайки, сохранения, репосты, комментарии с кодовым словом, подписки, DM.
Агент читает этот файл в `/reels-review`.

## Что считать «залетело»
- просмотры ≥ 3× медианы партии — хук сработал, делаем 3–5 вариаций;
- сохранения/репосты высокие при средних просмотрах — польза сильная, хук слабый: менять заголовок, оставить описание;
- комментарии с кодом ≥ 2% от просмотров — конверсия хорошая, можно масштабировать;
- просмотры высокие, кодов нет — описание/CTA не работает: править caption, не ролик.

## Цикл
Партия → Trial → 24–72 ч статистика → `/reels-review` → следующая партия на основе победителей.

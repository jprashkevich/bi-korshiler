# С чего начать: пошагово

## Шаг 1. Установить три программы (один раз, 15 минут)

1. **Claude Code** — приложение, в котором живёт агент: https://claude.ai/code → «Download» (есть версии для Mac и Windows). Войти своим аккаунтом Claude.
2. **Node.js** — на нём работает сборка видео: https://nodejs.org → кнопка «LTS» → установить, всё по умолчанию.
3. **ffmpeg** — обрабатывает видео.
   - Mac: открыть «Терминал», вставить `brew install ffmpeg` (если команда brew не найдена — сначала поставить Homebrew с https://brew.sh).
   - Windows: открыть PowerShell, вставить `winget install ffmpeg`.

Проверка: в терминале `node -v` и `ffmpeg -version` печатают версии, а не ошибку.

## Шаг 2. Скачать проект на компьютер

Вариант А (без терминала): установить GitHub Desktop → File → Clone repository →
`jprashkevich/bi-korshiler` → после клонирования вверху выбрать ветку
`claude/instagram-viral-reels-agent-kaq9nh` (или `main`, если ветка уже слита).

Вариант Б (терминал):
```
git clone https://github.com/jprashkevich/bi-korshiler.git
cd bi-korshiler
git checkout claude/instagram-viral-reels-agent-kaq9nh
```

Результат: на компьютере есть папка `bi-korshiler`, внутри неё `reels-agent`.

## Шаг 3. Открыть Claude Code в папке проекта

Открывать нужно **корневую папку `bi-korshiler`** (не `reels-agent`): команды
`/reels-…` лежат в её скрытой папке `.claude`.

- Приложение Claude Code: «Open folder» → выбрать `bi-korshiler`.
- Терминал: `cd bi-korshiler` → `claude`.

Проверка: набрать `/reels` — в подсказке появятся четыре команды.

## Шаг 4. Подготовить материал (до запуска, чтобы не тормозить)

Видео: 5–10 вертикальных роликов из галереи по 10–20 секунд без речи
(кофе, дорога, рабочее место, город, процесс работы). Скинуть на компьютер
(AirDrop, кабель, Google Drive) и положить в папку `bi-korshiler/reels-agent/footage/raw/`.

Ответы на вопросы интервью (можно просто продумать, агент спросит сам):
1. Кому вы помогаете и с какими запросами они приходят (5 болей своими словами клиентов).
2. 5 вопросов, которые вам задают снова и снова.
3. Что продаёте, сколько стоит, ссылка.
4. Что можно отдать бесплатно за кодовое слово: чеклист, шаблон, разбор, видео (это лид-магнит;
   если его нет — агент предложит сделать).
5. 3–5 фактов о вас, которые можно подтвердить (лет в теме, число клиентов, конкретный результат).
6. Тон: на «ты» или на «вы», что запрещено упоминать.

Необязательно, но сильно помогает: 20–40 скриншотов чужих рилсов из вашей ниши,
у которых просмотров заметно больше обычного для автора (на скриншоте должен быть
заголовок на экране и число просмотров). Положить в `reels-agent/hooks/inbox/`.

## Шаг 5. Настройка: `/reels-setup`

В Claude Code написать `/reels-setup` и отвечать на вопросы. Агент сам:
установит библиотеки для сборки видео (2–5 минут), обработает ваши видео,
заполнит профиль, покажет 6 вариантов оформления с картинками-превью и спросит,
какой нравится. В конце скажет, что готово. Если чего-то не хватает — напишет,
что именно (чаще всего: нет видео в `footage/raw`).

Если положили скриншоты в `hooks/inbox/` — дальше `/reels-hooks`: агент разберёт
заголовки и выпишет паттерны вашей ниши.

## Шаг 6. Первая партия: `/reels-batch`

Написать `/reels-batch`. Агент предложит 10 заголовков — можно попросить заменить
любые. Затем напишет описания, покажет 2–3 превью кадров и отрендерит видео
(примерно 30–60 секунд на ролик, 10 роликов — 5–10 минут).

Результат в папке `reels-agent/batches/<дата>-batch-01/out/`:
- `*.mp4` — готовые ролики;
- `captions/*.txt` — описание под каждый ролик (имя файла = имя ролика);
- `bot.md` рядом в папке партии — тексты для бота, если лид-магнит новый.

Переслать на телефон: папку `out` → AirDrop, или загрузить в Google Drive /
«Избранное» в Telegram и сохранить в галерею.

## Шаг 7. Бот (один раз на лид-магнит, 20 минут)

Зарегистрироваться в ManyChat (manychat.com), подключить Instagram.
Automation → New Automation → «Comment on a Post or Reel» → Any post.
Триггер: кодовое слово из `bot.md`. Вставить тексты из `bot.md`: публичный ответ,
сообщение в директ со ссылкой, отложенные сообщения. Проверить со второго аккаунта.

Без бота тоже можно начать: отвечать на кодовые слова вручную в директе.

## Шаг 8. Публикация

Instagram → «+» → Reel → выбрать mp4 → «Далее» → описание: вставить текст из
`captions/<имя>.txt` целиком → перед кнопкой «Поделиться» включить тумблер **Trial**
(«Пробный») → поделиться.

Режим: 5 роликов в день, интервал 1–3 часа, 3–5 дней подряд без выводов.
Партия из 10 роликов = 2 дня. Если тумблера Trial нет: проверить, что аккаунт
профессиональный (Creator или Business) и приложение обновлено; у части аккаунтов
функция появляется позже — тогда публиковать обычными рилсами.

## Шаг 9. Через 1–3 дня: `/reels-review`

Сделать скриншоты статистики каждого ролика (просмотры, сохранения, комментарии,
подписки), положить в любую папку проекта, например `reels-agent/tracking/`, и
написать `/reels-review`. Агент внесёт цифры в таблицу, скажет, какие заголовки
сработали и почему, и предложит план следующей партии. Ответить «да» — он соберёт
её сразу.

Дальше цикл: партия → публикация → статистика → партия. Все команды и файлы те же.

## Если что-то пошло не так

- «command not found: node / ffmpeg» — шаг 1 не завершён; перезапустить терминал после установки.
- Нет команд `/reels-…` — Claude Code открыт не в корневой папке `bi-korshiler` (шаг 3).
- Рендер упал — написать агенту «рендер упал, посмотри ошибку», он читает логи сам.
- Видео обрезалось не так — перезалить вертикальный исходник; горизонтальные видео режутся по центру.
- Текст мелкий — попросить агента «сделай заголовки короче» или сменить пресет на `caps`.

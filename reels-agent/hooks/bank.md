# Банк хуков для «тихих» рилсов

**Что это.** 300+ заголовков-шаблонов, сгруппированных по 20 паттернам, которые
повторяются в текстовых рилсах с большими охватами. Это не «готовые вирусные
фразы» (вирусность даёт сочетание хука, ниши и алгоритма), а **конструкции**,
которые агент адаптирует под профиль из `config/profile.yaml`.

**Как пользоваться (агенту).**
1. Взять 5–8 разных паттернов на партию, не повторять один паттерн более 2–3 раз.
2. Подставить в `{…}` конкретику из профиля: боли, FAQ, мифы, цифры из `proof`.
3. Переписать своими словами в тоне аккаунта. Шаблон — скелет, не финальный текст.
4. Проверить правила: ≤ 12 слов, ≤ 4 строк, ≤ 22 символов в строке, одна мысль.
5. В `batch.json` указать `pattern` — так в `/reels-review` будет видно, что сработало.

**Обозначения.** `{ниша}` — тема; `{результат}` — что хочет аудитория;
`{срок}` — время; `{N}` — число; `{боль}` — проблема словами аудитории;
`{роль}` — кто вы (коуч, нутрициолог, маркетолог…); `{клиент}` — кто аудитория.

# Мои собранные хуки

Сюда агент складывает заголовки из вирусных роликов вашей ниши, которые вы
скинули в `hooks/inbox/` (скриншоты, ссылки, текст). Правило отбора:
**просмотров заметно больше, чем у обычных роликов того же автора.**

Как скинуть материал:
- скриншоты экрана с заголовком и числом просмотров → `hooks/inbox/*.png|jpg`
- ссылки одной строкой → `hooks/inbox/links.txt`
- просто текст заголовков → `hooks/inbox/raw.txt`

Затем: `/reels-hooks` — агент разберёт, занесёт в таблицу и выделит паттерны.

# Тексты для бота (ManyChat / аналог)

Сценарий: зритель пишет кодовое слово в комментарии → бот отвечает в комментарии
и присылает материал в директ → через 1 день — дожим на следующий шаг.
Агент генерирует эти тексты для каждого лид-магнита из `config/profile.yaml`.

## Шаблон (один лид-магнит = один сценарий)

### 0. Триггер
- Кодовое слово: `{КОД}` (+ варианты написания: строчными, с точкой, с пробелом)
- Где ловить: комментарии к рилсам партии + директ

### 1. Публичный ответ в комментарии (чтобы другие тоже написали)
```
Отправила в директ 🙌 Проверь запросы, если не видишь
```

### 2. Первое сообщение в директ (сразу)
```
Привет! Вот {название материала}: {ссылка}

Внутри — {что внутри, 1 строка}.
Начни с {первый шаг}, это займёт {N} минут.

Если что-то не откроется — напиши «ещё», пришлю заново.
```
Правила: короче 500 знаков, ссылка в первом сообщении, один ясный первый шаг.

### 3. Вопрос через 1 день (вовлечение)
```
Привет ещё раз! Получилось открыть {материал}?
Если да — какой пункт откликнулся больше всего?
Отвечай одним словом, мне правда интересно.
```

### 4. Следующий шаг через 2–3 дня (мягкое предложение)
```
Многие после {материал} спрашивают: «а как это применить к моей {ситуация}?»

Для этого есть {следующий шаг: консультация / продукт / канал}:
{1 строка — что человек получит}.

Хочешь — напиши «{КОД2}», расскажу подробнее. Если нет — ничего страшного,
всё самое важное у тебя уже есть.
```

### 5. Если человек задаёт вопрос (ручной сценарий)
Бот не продаёт. Бот отвечает: «Передала {имя}, ответит лично в течение дня».

## Правила для всех текстов
- Обращение и тон — из `account.tone`.
- Никакого давления: «только сегодня», «осталось 3 места» — не используем.
- Ценность до предложения: сначала материал, потом вопрос, потом оффер.
- В каждом сообщении — одно действие.
- Для EN-аккаунта писать отдельный сценарий на английском.

## Чеклист настройки в ManyChat
1. Instagram → Automation → New → «Comment on a Post or Reel» → Any post.
2. Триггер: кодовое слово (все варианты написания).
3. Public reply: текст из п.1. DM: текст из п.2 с кнопкой-ссылкой.
4. Условие «Follow us» — по желанию (можно просить подписку до выдачи).
5. Smart Delay 1 день → п.3. Smart Delay 2 дня → п.4.
6. Протестировать со второго аккаунта до запуска партии.

# Шаблон описания под рилс (caption)

Цель описания — не «ещё текст», а переход **просмотр → действие**:
дать пользу, которую обещал хук, и создать желание получить следующий шаг.

## Структура (4 блока, 400–900 символов, лимит Instagram 2200)

```
[1] ХУК — повтор заголовка с экрана, слово в слово или усиленный
[пустая строка]
[2] ПОЛЬЗА — 3–5 строк конкретики: шаги / признаки / ошибки.
    Каждая строка — законченная мысль, которую можно применить сегодня.
    Без воды, без «как известно», без обещаний «изменить жизнь».
[пустая строка]
[3] МОСТ — одна фраза: что ещё есть и почему это нужно именно сейчас
[пустая строка]
[4] CTA — кодовое слово ЗАГЛАВНЫМИ, одно, в кавычках «…»:
    Напиши «{КОД}» в комментариях — бот пришлёт {материал} в директ.
[пустая строка]
[5] 3–5 нишевых хэштегов (без #reels #viral #рек)
```

## Правила

- Первая строка = хук. Instagram показывает только её до «ещё».
- Пользу давать **целиком**, не «секрет в директе». Доверие важнее дожима.
- Факты и цифры — только из `config/profile.yaml → expertise.proof`. Никаких выдуманных кейсов.
- Один CTA на описание. Одно кодовое слово. Никаких «ссылка в шапке» без кода
  (Trial-зрители не подписаны и в шапку не пойдут).
- Кодовое слово должно быть **уникальным для материала** и легко набираемым:
  ГАЙД, ПЛАН, ЧЕКЛИСТ, ХУКИ, СТАРТ. Не «гайд по рилсам 2026».
- Тон — из `account.tone`. На «ты» или на «вы» — как в профиле, без смешивания.
- Эмодзи: 0–3, только как маркеры списка, не в каждой строке.
- Запрещённые слова/темы из `account.forbidden` не используются.
- Для EN-аккаунта писать с нуля на английском, не переводить дословно.

## Пример

```
3 ошибки, из-за которых твои рилсы не видит никто:

1. Заголовок про тебя, а не про зрителя.
2. Первая секунда без текста на экране.
3. Один ролик в неделю и выводы «не работает».

Исправь первое — и уже увидишь разницу в охватах.

Я собрала 30 заголовков, которые можно адаптировать под любую нишу.
Напиши «ХУКИ» в комментариях — бот пришлёт список в директ.

#рилс #продвижение #экспертныйблог
```

## Варианты CTA по типу следующего шага

| Следующий шаг | CTA |
|---|---|
| Лид-магнит (файл) | Напиши «КОД» — пришлю файл в директ |
| Видео-урок | Напиши «КОД» — отправлю ссылку на разбор |
| Консультация | Напиши «КОД» — отвечу лично и расскажу, с чего начать |
| Товар | Напиши «КОД» — пришлю ссылку и промокод |
| Канал/рассылка | Напиши «КОД» — добавлю в закрытый канал |

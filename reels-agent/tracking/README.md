# Статистика партий

`stats.csv` — одна строка на один замер одного ролика. Замеры: через 24 ч и 72 ч.

| Колонка | Что писать |
|---|---|
| date_posted | дата публикации YYYY-MM-DD |
| batch | имя папки партии |
| reel_id | id из batch.json |
| pattern | паттерн хука (из batch.json) |
| hook | текст хука одной строкой |
| account | аккаунт (main / en / …) |
| checked_after_hours | 24 или 72 |
| views | просмотры |
| watched_full_pct | % досмотревших, если виден в статистике, иначе пусто |
| likes, saves, shares | по статистике ролика |
| comments_total | всего комментариев |
| keyword_comments | комментариев с кодовым словом |
| follows | подписок с ролика |
| dms | сообщений в директ по теме ролика |
| status | trial / shared_to_all / deleted |
| notes | что угодно: «IG предложил показать всем», «удалила» |

Можно заполнять руками в таблице или просто прислать агенту скриншоты статистики —
он сам допишет строки (`/reels-review`).

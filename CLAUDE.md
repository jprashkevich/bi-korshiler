# Репозиторий bi-korshiler

Два независимых проекта:

1. **Корень** — статический сайт «Лига Добрососедства» (index.html, about.html, css/, js/). См. README.md.
2. **`reels-agent/`** — агент для сборки «тихих» Instagram-рилсов (хук поверх b-roll через Remotion),
   описаний и текстов бота. Инструкция агента — `reels-agent/CLAUDE.md`,
   команды: `/reels-setup`, `/reels-hooks`, `/reels-batch`, `/reels-review`.

Работая над одним проектом, не трогай файлы другого.

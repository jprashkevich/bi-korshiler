# Yourt · плакаты А4

Печатные листы для пространств Yourt. Два языка на одном листе — казахский
и русский, равными по весу блоками. Тональность дружелюбная и простая.

| Набор | О чём | QR ведёт на | Статус |
|---|---|---|---|
| **booking** | Расписание и бронирование пространства | `community.bi.group/reservations/…` | собран, вариант **v3 «Кесте»** |
| **review** | Отзывы и идеи | `tunely.kz/q/…` | 4 варианта на выбор |

---

## Что где лежит

```
posters/
  assets/
    yourt-logo.svg      логотип yourt. в кривых (векторизован из растра, currentColor)
    qr/*.png            13 QR бронирования — только модуль кода, ~540 dpi на печати
    qr-review/*.svg     13 QR отзывов — вектор как есть (segno)
  build/
    content.mjs         текст и список пространств — бронирование
    content-review.mjs  текст и список пространств — отзывы
    design.mjs          токены, шрифты, шаңырақ, каркас страницы A4
    variants.mjs        4 варианта бронирования
    variants-review.mjs 4 варианта отзывов
    render.mjs          рендер обоих наборов (Playwright + Chromium)
    prep_qr.py          подготовка новых растровых QR бронирования
  out/
    booking/  review/   _variants (превью), pdf/, png/, сводный PDF
```

---

## Сборка

```bash
cd posters
node build/render.mjs preview <набор>            # превью вариантов
node build/render.mjs build   <набор> <вариант>  # все плакаты набора

node build/render.mjs build booking v3
node build/render.mjs build review  r1
```

Кладёт в `out/<набор>/`:

* `pdf/…pdf` — по листу на пространство, для печати;
* `png/…png` — то же в 300 dpi, для чатов и превью;
* `Yourt_<набор>_<вариант>_ALL.pdf` — все листы одним файлом.

Формат — ровно A4 (210×297 мм), без вылетов. Поля от 14 мм, любой офисный
принтер напечатает без обрезки. **Исключение — варианты с цветным полем
в край** (`booking/v4`, `review/r4`): нужна печать «без полей» или типография,
и заливка съедает заметно больше тонера.

## Варианты — бронирование

| | Вариант | Как выглядит |
|---|---|---|
| v1 | **Шаңырақ** | Тёплая бумага, монохром. QR лежит в «дымовом отверстии» шаңырақ. |
| v2 | **Ақ парақ** | Чистый лист, швейцарская типографика, волосяные линейки. |
| **v3** | **Кесте** ← собран | Полоса слотов со свободными окнами + три шага. Тёплый акцент. |
| v4 | **Болд** | Половина листа — синий блок с вывороткой. |

## Варианты — отзывы

Бриф: QR крупный. Во всех вариантах он от 88 до 120 мм.

| | Вариант | Как выглядит | Когда брать |
|---|---|---|---|
| r1 | **Пара к Кесте** | Тот же каркас, что у собранного плаката о бронировании: песочные карточки, глиняный акцент, QR 92 мм. | Если два плаката висят рядом — читаются одной серией. |
| r2 | **Үлкен QR** | QR 120 мм почти во весь лист, текста ровно столько, чтобы понять зачем сканировать. | Максимальная дальность считывания, минимум чтения. |
| r3 | **Диалог** | QR лежит в реплике; три темы подсказывают, о чём писать. | Если отзывов пока мало и людям нужен повод. |
| r4 | **Болд** | Глиняное поле сверху, белая QR-карточка садится на границу. | Коридор, лифтовый холл. |

Превью: `out/<набор>/_variants/`, там же лист сравнения `_contact_sheet.png`.

## Решения по дизайн-системе

**Шрифт — только Gotham** (Book / Medium / Bold / Black из `fonts/`).
TT Firs Neue в наборе есть, но в файле нет казахских глифов —
`Ғ ғ Қ қ Ң ң Ү ү Ұ ұ Һ һ Ө ө` отсутствуют, для казахского текста он не годится.
Gotham покрывает кириллицу и казахские буквы полностью.

**Мотив — шаңырақ**, вид юрты сверху. Рисуется кодом (`design.mjs`),
а не картинкой: любой размер, любая толщина линии, чистая печать.
id для `clipPath` генерируются счётчиком — в сводном PDF макет повторяется
13 раз, и одинаковые id ломали бы отрисовку.

**Палитра.** База — чернильный `#16181C` и бумага (белая либо тёплая
`#F4EFE7`). Акцент вынесен в токен и меняется одной строкой:
глина `#BE5A34` в наборе отзывов и в `booking/v3`, синий BI `#1B2A6E` в `booking/v4`.

**Типографика.** Короткие слова и тире привязаны неразрывным пробелом
(`typo()` в `content.mjs`), чтобы предлоги и союзы не висели в конце строки.

**QR.** Бронирование пришло растром в шаблоне 800×1050 — взят только модуль
кода, логотип и подписи рисует макет, иначе они дублировались бы. Отзывы
пришли вектором (segno) — инлайнятся как SVG, красятся из CSS и печатаются
без растеризации. Все 26 кодов проверены декодером после подготовки и после
рендера в PNG 300 dpi.

Названия для набора отзывов восстановлены по слагам QR
(`ala-` Алматы, `ast-` Астана, `atr-` Атырау) — проверьте написание пяти
новых пространств в `content-review.mjs`, если оно должно отличаться.

### Как добавить пространство

**Отзывы (вектор):** положить `qr-<slug>.svg` в `assets/qr-review/`
и добавить строку в `SPACES` (`content-review.mjs`).

**Бронирование (растр):**

```bash
pip install pillow
python3 build/prep_qr.py <папка-с-новым-qr>     # вырежет модуль в assets/qr/
```

Затем добавить строку в `SPACES` (`content.mjs`) и пересобрать.
`id` — имя файла без `qr_booking_` и `.png`.

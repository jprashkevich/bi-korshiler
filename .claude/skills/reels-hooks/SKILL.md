---
name: reels-hooks
description: Разбор вирусных хуков из ниши пользователя — читает скриншоты, ссылки и текст из reels-agent/hooks/inbox, извлекает заголовки и просмотры, определяет паттерны, заполняет hooks/my-hooks.md и предлагает адаптации под профиль.
---

Работай в папке `reels-agent/`. Прочитай `config/profile.yaml` и `hooks/bank.md` (список паттернов).

1. Просмотри `hooks/inbox/`: изображения открывай через Read (ты видишь картинки), `links.txt` и `raw.txt` читай как текст. По ссылкам без доступа к контенту — попроси скриншот.
2. Для каждого примера извлеки: заголовок на экране (дословно), просмотры, обычный уровень автора (если есть), паттерн из 20 в `bank.md`, почему сработал (1 фраза).
3. Запиши таблицу в `hooks/my-hooks.md`, заполни раздел «Выводы по нише».
4. Для каждого хука предложи адаптацию под профиль пользователя (колонка «Адаптация под меня») — по правилам вёрстки из `config/style.yaml → rules`.
5. Если в inbox пусто — объясни, что собрать (30–40 роликов из ниши, у которых просмотров заметно больше обычного для автора; скриншот с заголовком и просмотрами), и предложи пока работать из `bank.md`.
6. Итог в чат: 5–7 строк — главные паттерны ниши и 3 лучших адаптации. Остальное в файле.
